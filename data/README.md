# Data folder & preprocessing

ضع ملفات البيانات الخام في المسار `data/raw/` (أنشئ المجلد إذا لزم الأمر). يجب وضع المخرجات المُعالجة في المسار `data/processed/`.


تنسيق الملفات المُوصى به:

- `data/raw/` — الملفات الأصلية (CSV، JSON، Parquet)

- `data/processed/` — النسخ المُعالجة الناتجة عن `scripts/preprocess.py`


الاستخدام الأساسي:
```powershell
python scripts/preprocess.py --input data/raw/mydata.csv --output data/processed/mydata.cleaned.csv
```

ملاحظات:

- اسم عمود النص الافتراضي هو `text`. استخدم `--text-column` لتغييره.

- يُطبّق البرنامج النصي عمليات توحيد بسيطة للغة العربية (إزالة علامات التشكيل، وتوحيد الألف والياء، وإزالة التطويل).

- صُمّم هذا الهيكل ليكون قابلاً للتوسيع لاستخراج الميزات وتقسيم الكلمات حسب المهمة.

إذا كنتَ بحاجة إلى تطبيق قواعد تنظيف مُحدّدة، فأخبرني بها وسأقوم بتحديث `scripts/preprocess.py`.

# بيانات المشروع — دليل المجلد `data/`

نقطة البداية المتوقعة للبيانات المستخدمة في تحليل المشروع.

هيكل مقترح:

- `data/raw/` — البيانات الأولية كما استُلمت (لا تُرتكب تغييرات هنا)
- `data/processed/` — مخرجات عملية التجهيز المسبق (قابلة للاستخدام مباشرة من النماذج)

تشغيل السكربت التجهيزي (مثال):

```powershell
python scripts/preprocess.py --input data/raw/data.csv --output data/processed/data_clean.csv --text-col text
```

نصائح:
- احتفظ بنسخة من البيانات الأولية دائماً.
- لا ترفع بيانات حسّاسة إلى الريبو العام؛ استخدم روابط داخلية أو طرق مشاركة آمنة.
